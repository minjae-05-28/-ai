# 조상 기능 지도 (ancestor atlas)

`scripts/ancestor_atlas.py` — 학습 고리가 키운 나무(`results/learning_loop/tree.nwk`, 회차 10 기준 3,244종)에서 조상마다
세포 기능별로 어떤 유전자군을 가졌는지 복원하고, 판정마다 등급을 붙입니다. 가설 검정이 아니라 지금까지 검증된 모형을 쓰는 도구입니다.

## 만드는 법
1. 나무 전체에 G3c(사전 등록 9)를 다시 맞춥니다(학습 고리와 같은 함수 `fit_model`).
2. 분류군 이름마다(그 이름을 가진 종이 3개 이상) 90% 순수 무리의 공통조상 마디 하나를 고릅니다(`reliability.group_node`).
   나무 뿌리는 아모르페아 | 나머지로 뿌리를 내린 LECA입니다.
3. 유전자군을 GO slim으로 28개 세포 기능에 묶습니다(`MODULES`, 조상 결과를 보기 전에 정함). 기능이 알려진 유전자군만 칸에 들어갑니다
   (모형의 유전자군 약 1.8만 개 중 약 3,400개).
4. 판정 = 사후확률 ≥ 0.5면 "있었음". 등급 = 확신도 |2P − 1|: A ≥ 0.98, B ≥ 0.90, C ≥ 0.60, D 그 아래.
   등급별 실제 일치율은 사전 등록 11의 유전자 계통수 검사(시험 절반)로 다시 계산해 아틀라스에 함께 넣습니다
   (사전 등록 11에서 보정 신뢰도는 확신도보다 낫지 않았습니다: 무승부).

## 새 생물 넣기
- `python scripts/ancestor_atlas.py query "학명"`: 아틀라스에 있으면 바로, 없으면 UniProt 분류 서비스로 계통을 찾아 가장 가까운 무리의
  조상들을 보여 줍니다(인터넷 필요).
- 웹 페이지 "조상 기능 지도": 아틀라스에 든 이름(종·속·과·목·문 등)을 검색합니다. 없는 종은 속이나 과 이름으로 찾습니다.

## 결과 확인 (만든 뒤 처음 본 것)
- H2(엽록체 유전자 이동 처리) 없이 처음 만들었을 때 LECA에 엽록체·광합성 유전자군 36/53개가 "있었음"으로 나왔습니다. 이것은 알려진
  함정이라 H2를 넣고 다시 만들었습니다: LECA 엽록체 0/53, 식물 공통조상 47/53. 이 처리로 LECA의 예상 유전자군 수가 5,494 → 4,251개로 줄었습니다.
- 상식과 맞는지: 효모(Saccharomycetes) 섬모·편모 칸 0.09(편모를 잃음), 미포자충 미토콘드리아 칸 0.01(퇴화한 미토좀), 정단복합체충
  엽록체 칸 0.22(퇴화한 색소체).
- 칸의 진하기는 그 기능의 유전자군 중 있었던 비율이라, 특정 계통에만 생긴 유전자군이 많은 기능(예: 감수분열·유성생식에 섞인 정자 단백질)은
  깊은 조상에서 연하게 나옵니다. 그 기능이 없었다는 뜻이 아닙니다.
- 웹 페이지: `web/ancestor_atlas/index.html` + `atlas.json`(비공개 아티팩트로 게시).

## 한계
- 유전자군 있음/없음만 다룹니다. 서열(DNA·RNA), 조절, 구조, 소기관 형태는 알 수 없고 만들지도 않습니다.
- 나무는 분류 체계로 새 종을 붙여 키운 것이라 분류가 틀리면 조상 위치도 틀립니다.
- 일치율은 250종 나무에서 잰 값입니다. 3,244종 나무에서 같은지는 다시 재지 않았습니다.
- LECA 유전자군 수는 학습 고리 회차마다 4,507–5,516개로 흔들렸습니다. 가장 깊은 조상의 B·C·D 판정은 조심해서 읽어야 합니다.
