# 사전 등록 5: (C) 원핵생물 분포를 넣으면 종수 세기를 넘는가, (D) 초군을 가리고 예측하기

## C. 원핵생물 분포 (외부 기준: Vosseberg 2021, 사전 등록 3과 같은 대상·라벨·보정/시험 절반)
원핵 특징(유전자군마다, 미리 고정):
- `arch` = UniProt 고세균 프로테옴(Pfam 주석 있는 것, 생물 이름 중복 제거) 중 그 유전자군을 가진 비율
- `bact` = 같은 방식, 세균
- 입력에는 log(비율 + 0.001)을 씁니다. 진핵 빈도는 log(빈도 + 0.001).

학습형(보정 절반으로 로지스틱 회귀, C=1.0; 보정 절반 점수는 그 안의 5겹 교차검증):
| id | 입력 |
|---|---|
| P0 | 진핵 빈도만 (종수 세기의 보정판) |
| P1 | 진핵 빈도 + arch + bact |
| P2 | 진핵 빈도 + arch + bact + M7H2 사후확률 로짓(사전 등록 4의 최선 트리 처리) |

- **주 지표: 시험 절반에서 P1 − 현생 빈도 AUROC 차이**, 부트스트랩 95%(2,000회, 시드 0). 0 위 양성.
- 보조: P2 − P1 (트리가 원핵 정보 위에 더하는 것), P1 − P0.
- 예측: P1이 빈도를 **이김(+0.005 ~ +0.02)**. P2 − P1은 0 근처.

## D. 초군을 가리고 예측하기 (외부 라벨 없음 — 실제 관측으로 채점)
- 대상 초군: 우리 표본에서 잎이 10개 이상인 것 — Alveolata, Amoebozoa, Discoba, Fungi, Metamonada, Metazoa, Rhodophyta,
  Stramenopiles, Viridiplantae (9개, `leca2_pick.json`의 supergroup 이름).
- 초군 G마다: G의 잎을 모두 관측 안 됨으로 두고, 나머지로 예측합니다. 나무는 leca2_fast, 뿌리는 아모르페아(단일 뿌리; 뿌리 위치는
  G의 조상 마디 계산에 영향이 작음).
- 정답: 그 유전자군이 G의 잎 **하나 이상에 있음**(주), 보조로 G의 잎 **절반 이상에 있음**.
- 대상 유전자군: 남은 잎 중 하나 이상에 있는 것.
- 예측자:
  - **모형**: M7(공통 획득/손실 비)의 **G 공통조상 마디** 사후확률 — 나무에서 G가 어디 붙는지를 씀.
  - **종수 세기**: 남은 잎에서의 빈도.
- **주 지표: 9개 초군 평균 AUROC 차이(모형 − 세기)**, 부트스트랩 95%(유전자군 재표집 1,000회, 시드 0, 매회 9개 초군 모두 다시 계산).
  0 위 양성(나무가 세기 이상의 정보를 줌), 아래 음성.
- G의 공통조상 마디 아래에 G가 아닌 잎이 G 잎 수의 10%를 넘게 섞이면 그 초군은 보고는 하되 '혼입'으로 표시합니다(평균에는 포함).
- 예측: 모형이 세기를 **이김(평균 +0.01 ~ +0.03)** — 자매 갈래의 정보를 쓰므로. 초군마다 다를 수 있음.
