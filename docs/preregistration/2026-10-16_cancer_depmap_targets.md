# 사전 등록 21: 암에서 켜진 오래된 유전자는 암세포의 약점인가 — DepMap 의존성 검사와 표적 후보

작성 2026-10-16 UTC. 사전 등록 17–20의 결과는 보았지만, **DepMap·약물 자료는 아직 받지 않았고 아래 계산은 하나도 하지 않았습니다**.
결과를 본 뒤 이 문서를 고치지 않습니다(고치면 끝의 이탈 기록에 남김).

## 목적
최종 목표(암세포를 죽이는 방법)를 향한 계산 단계. 암에서 켜지는 단세포 시절 유전자가 암세포의 생존에 필요한지 보고,
실험해 볼 표적 후보 목록을 만듭니다. 결과는 가설이며 치료법이 아닙니다.

## 자료
- DepMap 공개 최신 배포: `CRISPRGeneEffect.csv`(Chronos 유전자 효과), `Model.csv`(세포주 계통 OncotreeLineage),
  `CRISPRInferredCommonEssentials.csv`(공통 필수 유전자). GitHub 서버에서 받아 유전자·계통별 요약만 저장.
- 의존: 유전자 효과 < −0.5. 유전자의 의존 비율 = 의존인 세포주 비율.
- 약물: DGIdb 상호작용 표에서 승인 약물(approved)과 연결된 유전자. 받지 못하면 표시만 빠짐.
- 종양 변화: 사전 등록 17의 품질 검사 짝 자료(13개 암종), 유전자별 암종 평균 LFC. 유전자 나이·UC/MC·증식 유전자 P는 16–18과 같음.

## 주 지표: 오래된 유전자의 선택적 의존 비율
- 대상 유전자: 13개 암종 평균 LFC의 중앙값 ≥ 0.5(암에서 켜짐), 나이 있음, P 아님, 공통 필수 아님.
- 선택적 의존 = 의존 비율 ≥ 10%.
- **UC 유전자와 MC 유전자의 선택적 의존 비율의 오즈비**, 95% 구간(유전자 부트스트랩 2,000회, 시드 0).
  하한 > 1 양성(오래된 유전자가 더 자주 약점), 상한 < 1 음성, 걸치면 무승부.

## 보조 지표 (보고만)
1. 같은 비교를 공통 필수 유전자를 넣고 했을 때.
2. 암에서 켜지지 않은 유전자(중앙값 < 0.5)에서 같은 오즈비(대조: 켜진 유전자에서만 나타나는지).
3. 나이 층(PS1–PS16)별 선택적 의존 비율.
4. **표적 후보(암종별)**: 그 암종에서 평균 LFC ≥ 1, UC, P 아님, 공통 필수 아님, 대응 계통 세포주의 의존 비율 ≥ 25%이고
   다른 계통 전체의 의존 비율보다 높은 유전자. 대응: BRCA→Breast, LUAD·LUSC→Lung, COAD→Bowel, LIHC→Liver,
   KIRC·KIRP·KICH→Kidney, PRAD→Prostate, STAD→Esophagus/Stomach, BLCA→Bladder/Urinary Tract, HNSC→Head and Neck,
   THCA→Thyroid. 계통 세포주가 10개 미만이면 빼고 보고. 후보마다 승인 약물 여부 표시.

## 예측 (틀려도 그대로 보고)
- 주 지표 오즈비 > 1, 양성.
- 대조(켜지지 않은 유전자)에서는 오즈비가 더 작음.
- 표적 후보: 계통 세포주가 충분한 암종 대부분에서 1개 이상. 후보 중 승인 약물이 있는 것은 절반 미만.

## 한계 (미리 적음)
- 세포주는 환자 종양과 다릅니다(배양 환경, 면역 없음). CRISPR 효과는 단백질 억제 약물 효과와 다를 수 있습니다.
- "다른 계통보다 의존이 높음"은 정상 세포 독성을 보장하지 않습니다(정상 세포 자료는 없음).
- 표적 후보는 계산 가설이며 실험 검증 전에는 아무 의미도 주장하지 않습니다.
