# 사전 등록 24: 회귀한 암세포의 SREBP–SCD 지질 합성 의존성 — 독립 자료 검증

작성 2026-10-16 UTC. 사전 등록 23에서 DepMap(Broad) CRISPR로 찾은 결과를 **다른 연구소의 CRISPR 실험과 환자 종양**에서 다시 봅니다.
아래 자료는 아직 받지 않았고 계산하지 않았습니다. 결과를 본 뒤 이 문서를 고치지 않습니다(고치면 끝의 이탈 기록에 남김).

## 가설 (사전 등록 23에서 나옴)
회귀 점수가 높은 암세포일수록 SREBP–SCD 지질 합성 경로에 더 의존한다.
**핵심 모듈 = SCD, SREBF1, SCAP, MBTPS1, MBTPS2**(SREBP 활성화 3단계 + 표적 효소; 23의 상위 결과에서 고르되 경로 정의대로 MBTPS2를 더함).

## 자료
- **Sanger Project Score**(Behan 등 2019; 다른 연구소, 다른 sgRNA 라이브러리): 세포주별 유전자 녹아웃 fold change. figshare 또는
  Sanger Cell Model Passports 다운로드. 세포주는 DepMap `Model.csv`의 SangerModelID로 연결.
- 회귀·증식 점수: 사전 등록 23의 `data/drug/lines.tsv`(CCLE 발현으로 계산, 그대로 사용).
- **TCGA 짝 자료**(사전 등록 17의 품질 검사 자료, 13개 암종).
- **GDSC2**(Sanger 약물 반응, ln IC50): 탐색용.

## 주 지표 (Project Score)
- 세포주마다 모듈 점수 = 다섯 유전자 fold change를 유전자별 z로 바꾼 평균(낮을수록 더 의존).
- 사전 등록 23과 같은 부분 상관(순위, 계통 평균 제거, 증식 점수 회귀 제거): 회귀 점수 ↔ 모듈 점수.
- 95% 구간: 세포주 부트스트랩 2,000회(시드 0). **상한 < 0이면 양성(재현됨)**, 하한 > 0 음성, 걸치면 무승부.
- 세포주가 100개 미만으로 연결되면 판정하지 않고 그렇게 보고.

## 보조 지표 (보고만)
1. Project Score에서 다섯 유전자 각각의 부분 상관.
2. 같은 계산을 DepMap CRISPR(사전 등록 23 자료)로 — 비교용(이미 본 결과).
3. **환자 종양**: 13개 암종마다 짝 환자의 δ_p(사전 등록 17 주 지표)와 SREBP 표적 유전자 평균 LFC(SCD, FASN, HMGCR, LDLR, INSIG1,
   SQLE, HMGCS1) 사이의 스피어만 상관. 양수(회귀가 심할수록 지질 합성 켜짐)인 암종 수.
4. GDSC2에서 표적에 SCD·SREBF·FASN·ACACA·HMGCR·SQLE가 있는 약물마다 부분 상관(회귀 점수 ↔ ln IC50; 음수 = 회귀 세포가 더 민감).

## 예측 (틀려도 그대로 보고)
- 주 지표 양성(다른 실험에서도 재현). 다만 상관 크기는 DepMap보다 작음.
- 환자 종양: 13개 중 절반 이상 암종에서 양의 상관.
- GDSC: 해당 약물이 거의 없을 것(있으면 방향만 보고).

## 한계 (미리 적음)
