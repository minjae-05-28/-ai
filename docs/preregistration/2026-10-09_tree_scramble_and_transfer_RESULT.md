# 결과 4: 계통수 망가뜨리기, 내공생 유전자 전달 처리

등록 파일(`2026-10-09_tree_scramble_and_transfer.md`, 커밋 7e75740)은 고치지 않았습니다.
실행: `python scripts/tree_scramble_transfer.py` → `results/leca_models/scramble_transfer.json`. 시험 절반 2,801개(LECA 1,953).

## 등록과 다름
- **별 모양 나무(T2)의 구현 버그를 고침.** 처음 실행에서 250갈래가 한 마디에 모이자 확률 250개의 곱이 float32에서 0이 되어
  가능도가 −∞가 됐고, T2 AUROC가 0.436으로 나왔습니다. 같은 모형을 '내부 가지 길이 10⁻⁶인 이진 나무'로 다시 만들어 해결했습니다.
  실제 나무는 마디마다 가지가 2–3개라 이 문제가 없고, 이전 결과는 영향받지 않습니다. 아래 T2는 고친 뒤의 값입니다.

## A. 계통수가 빈도 이상의 정보를 주는가
| 나무 | 시험 AUROC |
|---|---|
| T0 실제 나무 | 0.926 |
| T1 종 이름 섞은 나무(5회) | 0.953–0.957, 평균 **0.955** |
| T2 별 모양 | 0.936 |
| 현생 빈도 | 0.957 |

- 주 지표 T0 − T1 = **−0.029 [−0.035, −0.022] → 음성.** 실제 나무가 무작위로 섞은 나무보다 **나쁩니다.**
- T0 − T2 = −0.010 [−0.019, −0.000]. 실제 나무가 별 모양보다도 약간 나쁨.
- 예측: "T0 − T1은 0 근처" → **틀림**(0이 아니라 음수). "T2가 T0보다 높음" → 맞음. "T2가 빈도에 가까움" → 부분적(−0.021).
- 참고: 우리 유전체 자료의 가능도는 실제 나무가 훨씬 높습니다(M7: 실제 −624,164, 별 모양 −1,219,647). 나무는 유전체 자료를 잘
  설명하지만, 그 설명이 외부 LECA 판정과의 일치는 떨어뜨립니다.

### 탐색적 진단 (등록 안 함)
- 같은 종 표본에서 '초군마다 고르게 센 빈도'의 AUROC는 0.943, '몇 개 초군에 있나'는 0.933으로, 그냥 센 빈도(0.954)보다 낮습니다.
  계통적 중복을 바로잡는 쪽(실제 나무, 초군 균형)으로 갈수록 외부 기준과 멀어집니다.
- 해석 후보: Vosseberg의 LECA 판정에는 "종 범위의 15% 이상을 덮을 것"이라는 덮음 기준이 들어 있고, 그 덮음은 **그들의 종 표본에서
  센 종 수**입니다. 우리 표본도 비슷하게 잘 연구된 종에 쏠려 있다면, 그냥 센 빈도가 그 기준을 가장 잘 흉내 냅니다.
  즉 이 외부 기준은 '종 수 세기'에 구조적으로 유리하고, 계통수가 이 기준에서 지는 것이 곧 생물학적으로 틀렸다는 뜻은 아닐 수 있습니다.
  다만 이것은 사후 해석이며, 확인하려면 덮음 기준이 없는 외부 기준이 필요합니다.

## B. 내공생 유전자 전달(EGT) 처리
색소체 계통 잎 92개(250개 중). 색소체 쪽에 2배 넘게 몰린 유전자군 2,784개.

| 처리 | 보정 AUROC | 시험 AUROC | 음성 대조(광합성 5개, 모든 뿌리 P<0.1) |
|---|---|---|---|
| H0 M7 그대로 | 0.928 | 0.926 | **실패** (PsaA_PsaB 0.15–0.27) |
| H1 색소체 잎 전부 숨김 | 0.927 | 0.927 | 통과 (모두 0.000) |
| **H2 색소체 편중 유전자군만 숨김** | **0.933** | **0.930** | **통과** (모두 0.000) |

- 선택(보정 절반 기준): **H2.** 주 지표 H2 − H0 = **+0.0034 [+0.0008, +0.0060] → 양성.**
- 보조: H2 − 현생 빈도 = −0.027 [−0.034, −0.021]. 여전히 빈도는 못 이김.
- 예측: H2 선택, 0 < 차이 < 0.01, 음성 대조 통과, 빈도는 못 이김 → **모두 맞음.**
- 크기 비는 거의 그대로(0.796 → 0.791): 처리가 건드린 것은 주로 색소체 유전자처럼 원래 낮던 쪽의 순서입니다.

## 해석
- 수평이동 중 **엽록체 경유 전달(EGT)은 유전자군 유무 수준에서 다룰 수 있었습니다.** 작지만 구간이 0 위인 개선이 있고, LECA 2판의
  음성 대조 실패(광합성 유전자가 LECA에 있다고 나옴)가 사라졌습니다.
- 세균 → 진핵 수평이동은 이번에 다루지 않았습니다(유무 표로는 '오래된 유전자'와 구별할 근거가 없음).
- 계통수 시험은 더 근본적인 문제를 보였습니다. 이 외부 기준에서는 나무를 쓸수록 손해이고, 그 이유가 우리 모형의 결함인지,
  기준에 들어간 '종 수 덮음' 조건 때문인지는 아직 가릴 수 없습니다.
