# 사전 등록 7: 새 통합 모형 G3 (LECA 3판 후보)

작성 2026-10-10. 모형 G3는 **아직 구현하지도 돌리지도 않았습니다.** 결과 뒤에 고치지 않습니다. 구현 중 불가피하게 바뀐 것은
결과 파일에 "등록과 다름"으로 적습니다.

## 왜
지금까지 찾은 약점(사전 등록 3–5): 유전자군별 자유 획득률의 과적합(M7로 개선), 엽록체 경유 전달(H2로 개선), 원핵 정보 없음,
갈래별 손실 속도 차이 미반영. 이것들을 한 모형 안에 넣습니다. **모든 매개변수는 우리 유전체 자료의 가능도로만 정합니다**
(외부 라벨 사용 안 함).

## 모형 G3
2상태(있음/없음) 획득·손실 모형, 같은 나무(leca2_fast.nwk), 완전도 관측 모형 켬.
1. **속도 분포를 자료에서 배우기 (비모수 경험적 베이즈)**: (손실률, 획득/손실 비) 격자 54점(기존 L_GRID × Q_GRID)마다
   유전자군의 가능도를 구하고, 격자 위 사전분포 w를 EM으로 추정(최대 500회 또는 변화 < 1e-6). 유전자군마다 격자점의 사후 가중치로
   조상 사후확률을 평균합니다. 뿌리 사전확률은 격자점마다 정상 상태 g/(g+l).
   (M0 = 유전자군마다 최고 격자점 하나, M7 = 모두 같은 비 하나. G3는 그 사이.)
2. **원핵 분포별로 따로 배우기**: 사전분포 w를 세 층에서 따로 추정 — S0 원핵 프로테옴 어디에도 없음(고세균·세균 비율 둘 다 0),
   S1 둘 중 큰 값 < 0.1, S2 ≥ 0.1. 원핵에 흔한 유전자군이 '나중에 들어오기 쉬운' 속도를 갖는지를 자료가 정하게 합니다.
3. **축소 갈래의 손실 배수**: 기존 표시(유전자군 수가 중앙값의 60% 미만인 잎과 그 공통조상 아래 가지)에 배수 m ∈ {1, 2, 4, 8}을
   걸고, 전체 주변 가능도가 가장 큰 m을 고릅니다.
4. **엽록체 경유 전달**: 사전 등록 4의 H2 규칙 그대로(색소체 계통 빈도가 나머지의 2배 초과인 유전자군은 색소체 잎을 관측 안 됨으로
   둔 별도 적합의 값을 씀; 그 적합도 1–3을 똑같이 함).

LECA = 뿌리 4곳 최솟값(이전과 같음).

## 비교 대상
- **M7** (현재 최선 트리 모형), M0 (LECA 2판 모형), **종수 세기**(현생 빈도).
- 부품별 기여(보조): G3-a = 1만, G3-b = 1+2, G3-c = 1+2+3, G3 = 전부.

## 평가 (Vosseberg 시험지는 여러 번 봤으므로 주 판정에 쓰지 않음)
1. **주: 초군 가리고 예측하기** — 사전 등록 5D와 같은 9개 초군, 같은 정답(숨긴 초군의 잎 하나 이상에 있음), 같은 대상 유전자군,
   뿌리 아모르페아. 숨긴 초군마다 G3를 처음부터 다시 맞춤(EM, m 선택 포함; 엽록체 규칙은 남은 잎으로 계산).
   **주 지표: 9개 평균 AUROC(G3) − AUROC(M7)**, 부트스트랩 95%(유전자군 1,000회, 시드 0). 0 위 양성.
   보조: G3 − 종수 세기(같은 방법).
2. **보조: 다른 방식의 가짜 진화** — 실제 나무(아모르페아 뿌리)에서 유전자군 3,000개를 만듦(시드 0):
   손실률 로그정규(중앙 0.3, σ=1), 획득/손실 비 로그정규(중앙 0.15, σ=1), 뿌리 상태 50% 있음(정상 상태 아님),
   가지마다 손실 배수 로그정규(σ=0.5), 축소 갈래 가지는 추가 ×5, 20%의 유전자군은 무작위 5% 가지에서 획득률 ×20(수평이동 흉내),
   관측은 실제 완전도로 있음을 놓침. 정답 = 뿌리 상태. G3(층 하나로), M7, 종수 세기의 AUROC.
   보조 지표: G3 − M7, 부트스트랩 95%.
3. **참고: Vosseberg 시험 절반 AUROC**, 음성 대조(광합성 5개 모든 뿌리 P < 0.1), 크기 비.

## 예측 (틀려도 그대로 보고)
- 주: G3 − M7 **> 0 (+0.005 ~ +0.02)**. G3 − 종수 세기 > 0.
- 가짜 진화: G3 ≥ M7.
- Vosseberg 시험 절반: G3는 M7(0.926)보다 높고 종수 세기(0.957)보다는 낮을 것.
- 음성 대조 통과.
- 부품 중 가장 큰 기여는 1(속도 분포 학습).
