# 사전 등록 20: 단세포 시절 쪽 기울기는 초기(1기) 암에서도 보이는가

작성 2026-10-16 UTC. 사전 등록 17–19의 짝 표본 결과는 보았지만, **병기 자료와 짝 없는 종양 표본은 아직 받지 않았고 아래 계산은
하나도 하지 않았습니다**. 결과를 본 뒤 이 문서를 고치지 않습니다(고치면 끝의 이탈 기록에 남김).

## 목적
최종 목표(암 조기 발견)를 향한 첫 검사. 기울기가 진행된 암에서만 생기는 늦은 변화인지, 1기부터 있는 이른 변화인지 봅니다.

## 자료
- UCSC Xena TCGA `HiSeqV2`(사전 등록 17과 같은 33개 암종)와 같은 허브의 `<암종>_clinicalMatrix`.
- **정상 기준** = 그 암종 고형 정상 표본(11)의 유전자별 평균. 정상 표본 10개 이상인 암종만.
- 종양 = 원발 종양(01), 환자당 첫 표본. 짝이 없어도 씀.
- 병기: `pathologic_stage`가 있으면 그것, 없으면 `clinical_stage`. "Stage I/IA/IB…" → 1, II → 2, III → 3, IV → 4. 그 밖(X, 빈 값)은 뺌.
  병기 열이 없는 암종은 병기 분석에서 빠짐.
- 유전자 나이·UC/MC 경계·증식 유전자 P·면역/기질 표지는 사전 등록 16–19와 같음.

## 점수 (표본마다, GitHub 서버에서 계산)
- LFC = 표본 − 정상 기준. δ = 사전 등록 17의 발현 수준 보정 UC−MC 차이, 단 사전 등록 19처럼 **P와 표지 유전자를 뺀 유전자로**
  (십분위는 정상 기준 발현으로).
- 정상 표본의 δ도 계산(정상 기준에서 자기를 뺀 평균과 비교) — 구별력 계산용.
- 증식 s, 면역 i, 기질 t(사전 등록 18·19와 같은 정의).

## 주 지표: 1기 종양의 δ
- 1기 종양이 10개 이상인 암종마다 1기 종양 평균 δ, 95% 구간(종양 부트스트랩 2,000회, 시드 0). 하한 > 0 양성.
- **전체 판정: 해당 암종의 3분의 2 이상이 양성이면 "1기부터 보임" 지지**, 3분의 2 이상 음성이면 반대, 그 밖은 판단 보류.

## 보조 지표 (보고만)
1. 진행 추세: δ와 병기(1–4)의 스피어만 상관, 95% 구간(종양 부트스트랩). 병기 2개 이상에 각각 10개 이상인 암종만.
2. 보정 추세: δ = a + b·s + c·i + d·t + e·병기 의 e(병기 효과)와 구간.
3. 구별력: 1기 종양 대 정상 표본의 δ AUROC(1기 10개 이상, 정상 10개 이상인 암종). 기준선으로 증식 점수 s의 같은 AUROC.
4. 1기 종양에서 구성 보정 절편(사전 등록 19의 δ = a + b·s + c·i + d·t의 a).

## 예측 (틀려도 그대로 보고)
- 1기 δ 양성: 3분의 2 이상 → 지지(짝 표본에서 대부분 암종이 양성이었고, 짝 환자에도 초기 암이 섞여 있으므로).
- 진행 추세: 일관되지 않음 — 양의 추세가 분명한 암종은 절반 미만.
- 구별력: 1기 δ AUROC가 대부분 0.8 이상. 다만 증식 점수 s보다 높은 암종은 절반 정도.
