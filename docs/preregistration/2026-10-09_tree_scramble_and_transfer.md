작성 2026-10-09. 아래 실험은 **아직 하나도 돌리지 않았습니다.** 결과 뒤에 고치지 않습니다.
자료·라벨·보정/시험 절반·지표는 사전 등록 3(`2026-10-08_leca_model_variants.md`)과 같고, 판정은 **시험 절반**으로 합니다.
기본 모형은 사전 등록 3의 최선 트리 모형 **M7**(모든 유전자군 공통 획득/손실 비, 최대우도, 정상 상태 뿌리)입니다.

## A. 계통수가 빈도 이상의 정보를 주는가
| id | 나무 |
|---|---|
| T0 | 실제 나무(leca2_fast.nwk), 뿌리 4곳 최솟값 — 사전 등록 3의 M7 그대로 |
| T1 | 같은 나무 모양·가지 길이, **종 이름만 무작위로 섞음**(뿌리마다, 시드 1–5, 5회). 유전자 표와 완전도는 종을 따라 같이 섞임 |
| T2 | **별 모양 나무**: 모든 종이 뿌리에서 바로 뻗고, 가지 길이는 실제 나무의 뿌리→잎 평균 거리. 뿌리는 하나 |

- 주 지표: 시험 절반 AUROC의 **T0 − T1(5회 평균)**, 부트스트랩 95% 구간(유전자군 2,000회, 시드 0; 매회 다섯 개 섞은 나무의 평균 점수).
  0 위 = 실제 나무가 정보를 줌(양성), 0 포함 = 나무 모양이 정보를 주지 못함(무승부), 아래 = 실제 나무가 오히려 해로움(음성).
- 보조: T0 − T2, T2 − 현생 빈도.
- 예측: **T0 − T1은 0 근처(±0.02 안)**, **T2는 T0보다 높고 빈도에 가까울 것**(별 모양에서는 사후확률이 거의 빈도의 단조 함수가 되므로).
  즉 지금의 나무는 빈도 이상의 정보를 거의 주지 못한다고 예상합니다.

## B. 수평이동: 내공생 유전자 전달(EGT) 다루기
LECA 뒤에 생긴 엽록체 유전자가 2·3차 내공생으로 여러 초군에 퍼지면, 획득/손실 모형은 "LECA에 있었고 여러 번 잃음"으로 읽습니다
(LECA 2판 음성 대조 실패의 원인). 유전자군 유무 수준에서 쓸 수 있는 처리를 시험합니다.

**색소체 계통**(미리 고정, 계통 이름 일치): Viridiplantae, Rhodophyta, Glaucocystophyceae, Ochrophyta, Haptophyta, Cryptophyceae,
Dinophyceae, Euglenophyceae, Chlorarachniophyceae, Chromerida, Apicomplexa(비광합성이지만 색소체 유래 유전자 보유), Bolidophyceae.

| id | 처리 |
|---|---|
| H0 | M7 그대로(기준) |
| H1 | 색소체 계통의 잎을 모두 **관측 안 됨**으로 처리하고 M7로 다시 계산 (그들의 유무가 LECA 판단에 쓰이지 않음) |
| H2 | 유전자군마다 색소체 계통 쪽 빈도가 비색소체 쪽의 **2배 초과**이면 H1 값, 아니면 H0 값 (색소체 편중 유전자군만 처리) |

- 주 지표: 보정 절반 AUROC가 더 높은 쪽(H1 또는 H2)을 고르고, 시험 절반에서 **그것 − H0** 차이와 부트스트랩 95% 구간.
  0 위 = 수평이동 처리가 외부 일치를 개선(양성).
- 보조 1 (음성 대조, 판정 기준 미리 고정): 광합성 5개(Photo_RC, PSII, PsbP, Chloroa_b-bind, PsaA_PsaB)가 **모든 뿌리에서 P < 0.1**이면 통과.
- 보조 2: 고른 것 − 현생 빈도(시험 절반).
- 예측: H2가 선택되고 H0보다 **조금(0 < 차이 < 0.01)** 좋을 것, 음성 대조는 **통과**. 그래도 빈도는 못 이길 것.

## 이번에 다루지 않는 것 (한계로 적어 둠)
세균 → 진핵 수평이동(엽록체 경유가 아닌 것)은 유무 표만으로는 '오래된 유전자'와 구별할 근거가 없어 다루지 않습니다.
그것을 구별하려면 유전자군 안의 서열 계통(진핵 서열이 세균 서열 사이에 끼어 있는가)이 필요합니다.
