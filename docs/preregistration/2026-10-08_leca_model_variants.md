# 사전 등록 3: LECA 모형 여러 개를 외부 계통수 기준으로 시험

작성 2026-10-08. 아래 모형 중 **어느 것도 아직 돌리지 않았습니다**(현재 모형 M0만 사전 등록 2에서 전체 자료로 봤음).
이 파일은 결과 뒤에 고치지 않습니다. 벗어난 것은 결과 파일에 "등록과 다름"으로 적습니다.

## 배경
사전 등록 2에서 현재 모형(M0)은 Vosseberg 2021 계통수 LECA 판정과의 일치에서 현생 빈도보다 낮았습니다
(−0.088). 진단: 중간 빈도 유전자군을 늦은 획득으로 돌림. 원인 후보 두 가지:
(가) 뿌리 사전확률이 '정상 상태' g/(g+l)라서 드문 유전자군은 뿌리에서도 드물다고 가정함,
(나) 유전자군마다 획득률을 자유롭게 맞춰서 손실 여러 번보다 획득 몇 번을 고름.

## 자료 나누기 (모형을 돌리기 전에 고정)
- 대상: 사전 등록 2와 같음(그들이 계통수를 그린 Pfam ∩ 우리 유전자군, 5,489개). 라벨도 같음.
- **보정 절반 / 시험 절반**: Pfam 접근 번호(판 번호 제외)의 md5 첫 바이트가 짝수면 보정, 홀수면 시험.
- 모형 고르기와 학습형 모형의 학습은 보정 절반만 씁니다. 시험 절반은 마지막에 한 번 봅니다.
- 한계: M0의 시험 절반 성적은 사전 등록 2에서 이미 전체로 본 셈입니다. 새 모형들은 보지 않았습니다.

## 모형 (모두 같은 계통수 leca2.nwk, 같은 뿌리 4곳, 완전도 모형 켬, 축소 계통 배수 끔; LECA = 뿌리 4곳 최솟값)
| id | 획득/손실 비 | 뿌리 사전확률 |
|---|---|---|
| M0 | 자유 (현재 5개 앙상블) | 정상 상태 g/(g+l) |
| M1 | 자유 | 0.5 고정 |
| M2 | 자유 | 오늘날 빈도 |
| M3 | ≤ 0.3 | 정상 상태 |
| M4 | ≤ 0.1 | 정상 상태 |
| M5 | ≤ 0.1 | 0.5 고정 |
| M6 | ≤ 0.01 (돌로에 가까움) | 0.5 고정 |
| M7 | 모든 유전자군 공통 하나(유전체 자료의 최대우도로 고름) | 정상 상태 |
| M8 | 자유 | 모든 유전자군 공통 π 하나(최대우도, π ∈ {0.05,0.1,0.2,0.3,0.5,0.7,0.9}) |

M7–M9의 공통 매개변수는 우리 유전체 자료의 가능도로만 정합니다(외부 라벨 안 씀).

학습형(외부 라벨의 보정 절반으로 학습, 로지스틱 회귀):
| id | 입력 |
|---|---|
| S1 | 현생 빈도만 (빈도의 보정판 — 기준선 확인용) |

## 평가 (시험 절반)
- 각 모형: AUROC vs 현생 빈도 AUROC, 차이의 부트스트랩 95% 구간(2,000회, 시드 0); 빈도 층화 AUROC(10분위);
  크기 비 = 사후확률 합 / 그들의 LECA 수(1에 가까울수록 좋음).
- **선택 규칙**: 보정 절반 AUROC가 가장 높은 모형(학습형 포함)을 고르고, 그 모형의 시험 절반 차이로 판정합니다:
  0 위 양성, 아래 음성, 0 포함 무승부. 나머지는 모두 보고하되 판정에 쓰지 않습니다.
- 보조: 고른 모형이 트리 모형(M1–M9)이면, 그것의 Zmasek 2011(Dollo) 비교도 함께 적습니다(이미 본 기준이므로 참고).

## 예측 (틀려도 그대로 보고)
- 트리 모형 중 가장 좋은 것은 뿌리 사전확률을 바꾼 것(M1, M2, M8, M9 중 하나)이고, M0보다 시험 AUROC가 0.03 이상 높을 것.
- 그래도 트리 모형만으로는 현생 빈도를 넘지 못할 것(차이 ≤ 0).
- 학습형 S2/S3가 선택되고, 시험 절반에서 빈도를 이길 것(차이 > 0). 단 S1과의 차이는 작을 것.
