# lit_ordered_mito_loss

> Mitochondrial gene loss follows the same order across eukaryote lineages.

**출처**: [Johnston & Williams 2016, Cell Systems](https://www.eurekalert.org/news-releases/770432)  
**우리 데이터 판정**: consistent

## 우리 데이터로 다시 시험한 결과
Loss is strongly nested in mitochondria (containment 0.95 vs 0.78 random), explained by per-gene loss rates (fixed-fixed null 0.95).
