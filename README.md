# organelle-evo

**유전체가 줄어들 때, 무엇을 잃고 무엇을 바꿀까.**
공생 세균이 소기관이 될 때, 자유생활 생물이 기생생물이 될 때, 평범한 세균이 극한 환경으로 갈 때를 비교합니다. 실제 유전체 약 270개와 단백질체 260개에서 진화의 규칙을 학습하고, 그 규칙이 어디까지 통하는지 검증한 개인 연구 프로젝트입니다.

> *Learning the rules of genome reduction and adaptation across organelles, endosymbionts, eukaryotic parasites and extremophile bacteria, from ~270 genomes and 260 proteomes, re-testing published laws and correcting for phylogeny.*

| | |
|---|---|
| 데이터 | 진핵생물 120종(비교 쌍 99개), 세균·고세균 65종(비교 쌍 43개), 소기관·공생세균 유전체 64개, 단백질 조성 260개, NCBI 분류 242개 |
| 모델 | 경쟁위험 보존 모형, 선형 birth-death 과정, 저차원 모듈 모형, 분류 단계별 분산 성분 GLS(계통 보정), 시뮬레이션 기반 추론 |
| 결과물 | 버전 관리되는 법칙 저장소(데이터 법칙 20개 + 문헌 법칙 13개), 요약 도식, 조상 역추적기, 화성 실험 페이지, Obsidian 볼트 |
| 검증 | 계통·쌍을 통째로 빼고 맞히기, 기준선·암기 모델과 비교, 귀무모형, 계통 보정, 문헌 법칙 재현, 테스트 60개 |

## 세 층으로 정리한 결론

| 질문 | 무엇이 결정하나 | 핵심 근거 |
|---|---|---|
| **무엇을** 잃나 | 유전자마다의 **성향** (얼마나 여러 상황에서 필요한가) | 네 시스템 모두 소실 순서가 유전자별 소실률만으로 설명됨. 환경 정보를 넣어도 예측이 나아지지 않음(0.816 → 0.808) |
| **얼마나** 잃나 | **생활 방식** | 자유생활 10% → 기생 26% → 미토콘드리아까지 퇴화하면 72%. 계통 보정 후에도 유지 |
| 환경에 **어떻게 적응**하나 | **단백질 서열** | 환경 변화가 아미노산 조성 변화를 설명(R² 0.53–0.63). 유전자군의 90%가 같은 방향으로 바뀜 |

여기에 시스템 차이가 하나 있습니다. 기생생물과 극한 세균은 유전자를 거의 **하나씩 독립적으로** 잃습니다. 반면 소기관은 NDH 복합체나 광수확 안테나처럼 **복합체 단위로 묶어서** 잃습니다.

## 주요 결과

**유전자 소실**
1. **에너지와 번역 장치는 어디서나 끝까지 남는다.** RNA 중합효소는 시스템마다 반대로 갑니다. 미토콘드리아는 버리고(+1.02), 엽록체는 지킵니다(−2.55).
2. **에너지 유전자를 버리는 원인은 기생이 아니라 미토콘드리아 퇴화다**(+1.54). 기생을 세 축으로 나누자 분리됐습니다.
3. **잃는 순서는 계통을 넘어 같지만, 유전자별 성향 이상은 아니다.** 서로 다른 계통의 기생생물 2,567쌍 모두에서 무작위의 1.62배로 겹칩니다. 유전자별 소실률을 고정한 귀무모형보다는 엄격하지 않습니다.
4. **법칙은 처음 보는 계통에도 통한다.** 계통 하나를 통째로 빼도 법칙의 성능은 0.782 → 0.777로 거의 그대로입니다. 반면 유전자별 소실 빈도를 외운 모델은 0.865 → 0.802로 떨어집니다. 독립적으로 기생이 생긴 계통들이 같은 **종류의** 유전자를 잃는다는 뜻입니다.
5. **기생생물이 늘리는 것은 영양을 빼오는 유전자다.** 아미노산 수송체(11계통 중 6곳)와 퓨린 재활용 효소(7곳)가 독립적으로 늘었습니다.
6. **소기관은 묶음으로 잃는다.** 홍조류 계열 색소체는 NDH 복합체를, 녹색 계열은 광수확 안테나를 통째로 잃습니다. 묶음을 모델에 넣으면 남은 유전자를 맞히는 점수가 미토콘드리아 0.923 → 0.964, 엽록체 0.832 → 0.915로 오릅니다.

**단백질 서열**

7. **온도 적응**: 고온성일수록 I·V·Y·W·R·E·L이 많습니다. 최적 온도와의 상관은 0.82로, Zeldovich 2007을 재현했습니다. 이 비율 하나로 처음 보는 계통의 최적 온도를 오차 약 10°C로 맞힙니다.
8. **염분 적응**: 호염균 단백질은 산성입니다. 막단백질과 수송체는 덜 바뀌고, 흔한 핵심 세포질 단백질이 더 산성화됩니다.
9. **영양 적응**: 빈영양 세균은 아미노산 곁사슬의 질소를 줄입니다. 이 신호는 계통 보정을 거친 뒤에야 드러났습니다(보정 전 p 0.70 → 보정 후 p 0.003). 하지만 **GC 함량으로 설명됩니다**(아래).
10. **공생 세균의 AT 편향**: 유전체가 작을수록 F·Y·M·I·N·K가 늘고 단백질이 염기성이 됩니다. 대장균 등전점 6.6, 부크네라 약 10입니다. 원인은 크기가 아니라 GC 감소입니다(GC와 FYMINK r −0.98).

**계통 보정**: NCBI 분류 체계로 분류 단계별 분산을 추정해 다시 검정하면 **14개 법칙 중 13개가 유지됩니다**(세포 안 생활 효과만 탈락, p 0.10). 리보솜 단백질 서열로 만든 실제 계통수로 다시 하면 **12개**가 유지되고, 정렬을 다시 뽑은 부트스트랩 계통수 20개 모두에서 같은 12개가 유지됩니다. 추가로 빠진 것은 공생세균 FYMINK ~ 유전체 크기(p 0.06, 13종)인데, 이미 GC로 설명되는 법칙입니다.

**GC 교란 검증**: 아미노산 조성은 유전체 GC 함량에 크게 좌우됩니다(FYMINK와 r −0.96, GARP와 +0.98). 그래서 GC를 공변량으로 넣고 다시 검정했습니다(`gc_confound_v1`).

네 가지 방식으로 거듭 검정했습니다. 분류 체계 보정, **리보솜 단백질 서열 계통수**(56–34개 유전자군 연결, FastTree), 유전체 GC, 코돈 셋째 자리 GC(GC3, 돌연변이 편향에 더 가까움).

| 법칙 | GC / GC3 넣은 뒤 남은 효과 | 서열 계통수 + GC | 판정 |
|---|---|---|---|
| 온도 → IVYWREL (종 / 쌍) | 97% / 97%, 쌍 102% | 유지 | **적응, 모든 검정 통과** |
| 온도 → 전하−극성 (종 / 쌍) | 88% / 83%, 쌍 97% | 유지 | **적응, 모든 검정 통과** |
| 염분 → 산성 과잉 (종 / 쌍) | 96% / 99%, 쌍 94% | 유지 | **적응, 모든 검정 통과** |
| 빈영양 → 질소 절약 | 13% / −1% | 탈락 | GC로 설명됨 |
| 무산소 → FYMINK | 19% / 32% | GC3 기준만 일부 유지 | 대부분 GC, 남은 효과는 불확실 |
| 공생세균 크기 → FYMINK | 효과 사라짐 | 탈락 | GC로 설명됨 (Moran의 돌연변이 편향) |
| 공생세균 크기 → 염기성(등전점) | 24% / 79% | 탈락 (13종) | 불확실: GC3 기준으로는 남지만 표본이 작음 |

온도와 염분 적응은 GC와 무관한 진짜 서열 적응입니다. 질소 절약과 AT 편향은 GC 변화를 통해 일어납니다. 다만 GC 자체가 적응일 수 있어서(AT 염기쌍은 GC보다 질소가 적어, 빈영양 세균의 낮은 GC는 질소 절약 전략이라는 가설이 있습니다), "적응이 아니다"가 아니라 "**아미노산 선택이 아니라 GC 수준에서 일어난다**"가 정확한 결론입니다.

## 문헌과의 관계

이미 발표된 법칙 13개를 출처와 함께 모아 우리 데이터로 다시 시험했습니다(`laws/literature/laws.json`). 10개 일치, 2개 부분 일치, 1개 검증 불가입니다.
- **재현한 것**: 유전자 소실 성향(Krylov 2003), 미토콘드리아 소실 순서(Johnston & Williams 2016), 조절 유전자 스케일링 지수 ≈2(van Nimwegen 2003; 우리 1.95, 보정 후 1.80), Black Queen 카탈레이스 소실(Morris 2012), 고온 IVYWREL(Zeldovich 2007) 등
- **부분 일치**: 미토콘드리아에서 배운 보존 규칙이 엽록체에도 일부 통하지만(Giannakis 2022), 시스템별 규칙이 더 잘 맞습니다. 소수성 단백질이 남는 효과는 미토콘드리아에서만 보입니다.
- **새로울 수 있는 것** (아직 주장 전 단계): 다섯 종류의 유전체 변화를 한 틀로 비교한 것, "순서 = 성향"을 귀무모형으로 검정한 것, 환경이 유전자 소실은 설명하지 못하고 서열 변화는 설명한다는 분리

## 정직한 숫자

| 과제 | 점수 | 비교 |
|---|---|---|
| 처음 보는 기생생물이 잃는 유전자군 | AUROC 0.78 | 복제 수 0.64, 암기 0.87 |
| 처음 보는 **계통** 전체 | AUROC 0.777 | 암기 0.802 |
| 처음 보는 극한 세균이 잃는 유전자군 | AUROC 0.816 (환경 정보 없이) | 환경 정보 추가 0.808, 암기 0.804 |
| 환경 변화 → 아미노산 조성 변화 | R² 0.53–0.63 | 유전자 소실 예측에는 효과 없음 |
| 위 법칙에 ΔGC 추가 | R² 0.49–0.64 | 온도·염분은 GC와 무관 |
| 새 특성(발현량·오페론·도메인) 추가 | 기생 0.761 → 0.766, 극한 세균 0.819 → 0.823 | 차이 +0.005 [0.003, 0.009], 79쌍 중 71쌍에서 상승 |
| 암기 + 법칙 결합 (예측 도구) | 기생 0.814, 극한 세균 0.860 | 암기만: 0.798, 0.844 |
| 유전체 하나로 조상 복원 | AUROC 0.78 | 사전 지식만 0.77 |

**신뢰구간과 다중 비교** (`scripts/run_robustness.py`): 계통 단위로 다시 뽑는 부트스트랩을 했습니다.
- 처음 보는 계통에서 암기가 법칙보다 나은 폭: +0.025 [0.011, 0.036]
- 극한 세균에서 환경 축이 더하는 몫: −0.000 [−0.004, +0.003]. 효과가 없다는 결론이 구간으로도 확인됩니다.
- 계통 보정·GC 검증의 26개 검정에 거짓 발견률 보정(Benjamini-Hochberg)을 해도 판정이 바뀌는 법칙은 없습니다.

**천장은 어디인가** (`scripts/run_ceiling.py`): 같은 조상에서 같은 생활 방식으로 간 형제 계통들의 소실로 맞히면, 기생생물 0.90, 극한 세균 0.86이 나옵니다. 어떤 모델도 넘기 어려운 상한입니다.
- 기생생물: 남은 0.10은 계통마다의 우연(표류)입니다. 형제 계통 정보(0.90)와 다른 계통에서 배운 것(암기 0.80, 법칙 0.78)의 차이 0.10은 그 계통만의 역사라서, 계통을 넘는 법칙으로는 닿을 수 없습니다.
- 그래서 처음 보는 계통을 맞히는 문제에서 법칙이 더 올라갈 여지는 대략 0.78 → 0.80 언저리입니다. 점수를 크게 올리려면 가까운 친척 계통의 데이터가 필요합니다.

## 별도 실험

- **화성 무작위 법칙 실험**: 학습한 법칙과 별개로, 최소 세포에 무작위 진화 법칙 수백 개를 적용해 화성 환경 변화를 따라가게 했습니다.
  - 어떤 법칙에서든 과염소산염 호흡, 저온·삼투 보호, DNA 수선 강화, 편모 소실이 나타났습니다.
  - 유전자를 받아올 다른 생물이 없는 고립 조건에서 환경이 급변하면 64.5%만 살아남았습니다.
  - 학습한 법칙으로 미래를 예측하는 작업(기후 변화 병원체)은 검증이 약해서 중단했습니다.

```

4 법칙 학습         보존 위험도 / 복제·소실 birth-death / 모듈 / 서열 조성 축 법칙
5 검증             계통·쌍 빼고 맞히기, 기준선·암기, 귀무모형, 계통 보정, 문헌 법칙 재현
6 공개             법칙 저장소, 요약 도식, 체험 페이지, Obsidian 볼트
```

## 한계

- 찾은 것은 인과가 증명된 법칙이 아니라 통계적 경향입니다.
- 서열 계통수는 리보솜 단백질만으로 만든 FastTree 계통수 하나입니다. 부트스트랩 계통수 20개로 불확실성을 확인했습니다.
- GC 교란은 유전체 전체 GC로만 통제했습니다. NCBI가 약 절반의 유전체 GC를 정수 %로 반올림해 줘서 ±0.5%p 오차가 있습니다(데이터 카드 `docs/DATA.md` 참고). 코돈 셋째 자리 GC(GC3)나 유전자별 GC는 보지 않았습니다. GC가 환경에 반응한 결과라면 GC를 넣는 것이 진짜 효과까지 지울 수 있습니다(과보정).
- 조상 대신 현생 친척 종을 조상 대리로 씁니다.
- 유전자 수준은 유전자군이 있는지 없는지만 봅니다. 서열 수준은 단백질 전체와 도메인 단위의 조성까지만 봤습니다.
