# 법칙 저장소

학습된 진화 법칙을 버전별로 고정해 둔 곳입니다. 각 파일에는 계수와 95% 신뢰구간, 모델 식, 데이터 출처, 그리고 **적용 범위(scope)**가 함께 기록되어 있습니다.

## 저장소가 둘로 나뉘어 있습니다

| 폴더 | 대상 | 학습 데이터 |
|---|---|---|
| `laws/*.json` | 미생물과 단세포 진핵생물, 소기관 | 세균·고세균 86종, 진핵생물 142종, 실제 유전체 155개 |
| `laws/animals/*.json` | **동물 세포** | 동물 69종(핵 단백질체), 18개 분류군 |

**두 저장소의 계수를 섞어 쓰면 안 됩니다.** 정리 차원이 아니라 측정 결과입니다. 미생물
온도 법칙을 동물에 적용했을 때 미토콘드리아 단백질체에서는 **부호가 반대**로 나왔고
(`laws/animals/animal_temperature_v1.json`), 핵 단백질체에서는 부호는 같지만 5배 약하며
분류군 검증을 통과하지 못했습니다. 세균에게 "서식지 온도"는 곧 세포 온도이지만, 동물은
체온을 조절하거나 환경과 다른 온도에서 살기 때문에 같은 변수가 아닙니다.

코드에서도 분리됩니다. `organelle_evo.laws.registry_for(catalog)`가 카탈로그별로 읽고 쓸
저장소를 정하고, 모르는 카탈로그는 미생물 저장소로 조용히 넘어가지 않고 오류를 냅니다.

### 법칙별 환경 카드 (`environments/`)

법칙마다 **어떤 환경의 데이터에서 나왔는지**(온도·염분·산소·방사선·영양, 생활 방식, 동물 세포 온도·삼투압, 측정 GC의
범위)와 **환경별로 어떤 결과가 나왔는지**(95% 구간이 0을 벗어난 효과, 통과/탈락 판정)를 `environments/<id>.json`에
따로 두었습니다. 요약표는 [`environments/README.md`](environments/README.md). 범위 밖 환경에 쓰면 외삽입니다.
`scripts/build_law_environments.py`로 다시 만들며, 법칙 파일은 건드리지 않습니다.

이후 분석은 이 법칙들을 **학습에 섞지 않고**, 비교 대상이나 기준 예측기로만 사용합니다. 불러오기:

```python
from organelle_evo.laws import load_law
law = load_law("endosymbiosis_v1")
law.weights["mitochondrion"], law.ci95["mitochondrion"], law.scope
```
